# BYNOVA Portfolio Frontend

## Scope
- Recreate the supplied one-page BYNOVA portfolio at `/`, matching its dark futuristic composition, content hierarchy, sections, cards, and responsive behavior.
- Use the supplied BYNOVA logo artwork in the site header while preserving its original proportions.
- Add cohesive original visuals for the opening scene, portfolio projects, and supporting landscape artwork.

## Structure
- Build reusable React and TypeScript sections for navigation, services, portfolio, process, company benefits, testimonials, call-to-action, and footer.
- Use Redux Toolkit for shared interface state such as the mobile navigation and selected portfolio item.
- Use React Query for typed portfolio data, cached through the existing app-level Query Client.
- Add accessible navigation, labels, focus states, meaningful image descriptions, and reduced-motion behavior.

## Visual System
- Define BYNOVA’s navy, cyan, violet, magenta, and neutral palette as semantic tokens.
- Use a geometric display typeface with a clean body face, compact corners, fine blue borders, and restrained neon highlights.
- Match the reference’s dense desktop layout and adapt it cleanly for tablet and mobile screens.

## Validation
- Check the complete page at desktop and mobile sizes, including navigation and portfolio interactions.
- Confirm the page has BYNOVA-specific title, description, and social metadata.
